# اطلب على قدّك

صفحة تفاعلية لفكرة مقدَّمة في هاكاثون الفقد والهدر الغذائي.

**الفكرة:** التوصيل المجاني اللي يجي دفعة وحدة عند حد معيّن (مثل 35 ريال) يخلي إضافة أكل أرخص من دفع رسوم التوصيل، فيطلب الزبون أكل ما يحتاجه.

**الحل:** خصم على التوصيل يكبر بالتدريج مع قيمة الطلب لين يصير التوصيل مجاني عند نفس الحد. بهالطريقة كل صنف تضيفه له ثمن واضح، وما يصير فيه صنف "ببلاش".

الموقع كله في ملف واحد: `index.html`، وما يحتاج أي أدوات بناء.
